# OrehTV

Домашний медиасервер и приложение для Android TV: каталог фильмов и сериалов как у стримингов, автоматический выбор
источника и запуск в лучшем качестве, всё внутри домашней сети.

Проект личный и развивается для своих. Исходный код не публикуется; здесь — готовые сборки, конфигурация и установка.

## Как это устроено

```
Android TV (приложение) ──▶ сервер в домашней сети (один docker-compose)
                             ├─ Caddy       единственный вход, только домашняя сеть
                             ├─ API         каталог, подборки, журнал, админка, обновления
                             ├─ JacRed      индекс раздач, обновляется сам
                             ├─ TorrServer  видео
                             └─ discovery   отвечает телевизору «я здесь» (Linux)
```

Снаружи ничего не публикуется; пароль и ключи живут только на сервере.

## Требования

- Сервер: Linux с Docker (amd64 или arm64 — мини-ПК, Raspberry Pi 4/5, NAS с Docker) или Windows с Docker Desktop;
  4 ГБ памяти, 15 ГБ диска.
- Телевизор: Android TV / Google TV 8.0+.
- Ключ TMDB по желанию (бесплатная регистрация на themoviedb.org), аккаунт TorBox по желанию.

## Установка

### 1. Сервер

Linux — одной командой (нужен установленный Docker):

```bash
curl -fsSL https://raw.githubusercontent.com/chuck-uz/OrehTV/main/install.sh | bash
```

Windows — в PowerShell (нужен запущенный Docker Desktop):

```powershell
irm https://raw.githubusercontent.com/chuck-uz/OrehTV/main/install.ps1 | iex
```

Установщик проверит Docker, память и диск, предложит скачать снимок базы раздач (около 2,5 ГБ; без него база
соберётся сама примерно за сутки), запустит контейнеры и напечатает адрес мастера и **код**.

### 2. Мастер первого запуска

Откройте напечатанный адрес вида `http://192.168.1.50/setup`, введите код, пароль админки, при желании ключи
TMDB и TorBox. Дальше всё настраивается в админке `/admin/` (логин `admin`).

### 3. Телевизор

Установите `tvoreh-<версия>.apk` из [Releases](../../releases) (например, через приложение Downloader). При первом
запуске приложение найдёт сервер в сети само; на Windows-сервере — введите адрес, который напечатал установщик.
Первое устройство подключается автоматически, остальные — по коду с экрана телевизора в админке.

## Обновления

- Приложение: сервер раз в несколько часов забирает свежий релиз отсюда и предлагает обновление на телевизоре.
- Сервер: кнопка «Обновить сервер» в админке и ночное автообновление (скоро).
- Вручную: `docker compose pull && docker compose up -d` в каталоге сервера.

Что лежит рядом: `docker-compose.yml`, `Caddyfile`, `.env.example`, `jacred/config/init.yaml` — те же файлы,
что ставит установщик. Список изменений — в [CHANGELOG.md](CHANGELOG.md).
