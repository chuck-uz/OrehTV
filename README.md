# OrehTV

Домашний медиасервер и приложение для Android TV: каталог фильмов и сериалов как у стримингов, автоматический выбор
источника и запуск в лучшем качестве, всё внутри домашней сети.

Проект личный и развивается для своих. Исходный код не публикуется; здесь — готовые сборки и инструкция.

## Как это устроено

```
Android TV (приложение) ──▶ сервер в домашней сети (один docker-compose)
                             ├─ Caddy       единственный вход, только домашняя сеть
                             ├─ API         каталог, подборки, журнал, админка
                             ├─ JacRed      индекс раздач, обновляется сам
                             └─ TorrServer  видео
```

Снаружи ничего не публикуется; ключи и настройки живут только на сервере.

## Требования

- Сервер: Linux с Docker (amd64 или arm64) или Windows с Docker Desktop; 4 ГБ памяти, 15 ГБ диска.
- Телевизор: Android TV / Google TV 8.0+.
- Ключ TMDB по желанию (бесплатная регистрация), аккаунт TorBox по желанию.

## Установка

_Установщик и инструкция появятся в ближайших релизах._ Пока:

1. На сервере: скачать `server-<версия>.tar.gz` из [Releases](../../releases), распаковать, заполнить `.env`
   по `.env.example`, выполнить `docker compose up -d`.
2. На телевизоре: установить `tvoreh-<версия>.apk` из Releases (например, через Downloader) и указать адрес сервера.
3. Дальше обновления приложения приходят с вашего сервера сами.

## Обновления

- Приложение: сервер раз в сутки забирает свежий релиз отсюда и предлагает обновление на телевизоре.
- Сервер: кнопка «Обновить сервер» в админке и ночное автообновление.

Список изменений — в [CHANGELOG.md](CHANGELOG.md).
