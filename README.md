# TVOREH

TVOREH — это приложение для Android TV и небольшой сервер, который стоит у вас дома. На телевизоре каталог фильмов и сериалов с подборками, коллекциями и поиском. Нажимаете «Смотреть», сервер находит раздачу с русской озвучкой и отдаёт видео телевизору. Обычно в 4K, если такая раздача есть и сеть тянет.

Работает только в домашней сети. Подписок и рекламы нет.

Проект личный, его делают для себя и друзей. Исходного кода здесь нет, только готовые сборки, файлы сервера и установщик. Подробная справка лежит в [Wiki](../../wiki).

## Что понадобится

- Компьютер, который будет всё время включён: Linux с Docker (подойдут мини-ПК, Raspberry Pi 4 или 5, NAS) или Windows с Docker Desktop. Памяти от 4 ГБ, свободного места от 15 ГБ.
- Телевизор или приставка на Android TV / Google TV 8.0 и новее.
- По желанию ключ TMDB (бесплатный, на themoviedb.org) и аккаунт TorBox, чтобы фильмы стартовали за секунды. Без них тоже всё работает.

## Установка

Сервер на Linux ставится одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/chuck-uz/OrehTV/main/install.sh | bash
```

На Windows запустите Docker Desktop, откройте PowerShell и выполните:

```powershell
irm https://raw.githubusercontent.com/chuck-uz/OrehTV/main/install.ps1 | iex
```

Установщик спросит, скачать ли снимок базы раздач. Соглашайтесь: это около 2 ГБ, зато поиск заработает сразу, а не через сутки. В конце он напечатает адрес вида `http://192.168.1.50/setup` и шестизначный код. Откройте адрес в браузере, введите код и придумайте пароль админки. Остальное потом настраивается в админке по адресу `/admin/`, логин `admin`.

Приложение на телевизор ставится файлом `tvoreh-<версия>.apk` из [Releases](../../releases), удобнее всего через Downloader. При первом запуске оно само найдёт сервер в сети. Если сервер на Windows, адрес придётся ввести вручную, установщик его печатает.

Первый телевизор пускается сам. Для остальных впишите в админке, в разделе «Устройства», ID, который телевизор покажет на экране.

Пошагово, с точными названиями кнопок, это расписано в вики: [установка сервера](../../wiki/Установка-сервера) и [телевизор](../../wiki/Телевизор).

## Обновления

Приложение обновляется само: сервер забирает отсюда новые версии, а телевизор при запуске предлагает обновиться. Сервер каждую ночь в пятом часу скачивает свежую версию и перезапускается за минуту.

Если сервер ставили давно и автообновления у него нет, просто запустите команду установки ещё раз. Настройки и база останутся.

Что поменялось в каждой версии — в [CHANGELOG.md](CHANGELOG.md).

## Что лежит в репозитории

`docker-compose.yml`, `Caddyfile`, `.env.example` и `jacred/config/init.yaml` — те же файлы, что ставит установщик. Они пригодятся, если хочется собрать сервер руками. Сам сервер состоит из пяти контейнеров: Caddy принимает запросы, API отвечает за каталог, админку и обновления, JacRed хранит базу раздач, TorrServer качает видео, а discovery помогает телевизору найти сервер в сети (только на Linux).

Порты 80 и 42069 в роутере наружу не пробрасывайте. Сервер рассчитан на домашнюю сеть.
