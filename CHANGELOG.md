# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версия приложения `MAJOR.MINOR.N`, `N` — номер сборки (до 0.9 версии были `0.1.N`).
Каждая сборка выходит сразу, поэтому изменения записаны по версиям `MAJOR.MINOR`: всё, что в разделе, уже вышло.

## [0.13] — с 2026-10-27

### Приложение

- Страна производства рядом с годом и оценками: на главной, в коллекциях и перед запуском фильма.

### Сервер

- Админка: переключатель «Убрать аниме» — аниме пропадает из подборок, коллекций и поиска на всех телевизорах сервера.

## [0.12] — с 2026-10-27

### Приложение

- Карточка: страны производства и статус сериала — «Идёт», «Завершён», «Закрыт» или «Скоро».
- Поиск: статус сериала на постере и фильтр «Только завершённые» (вместе с закрытыми).

## [0.11] — с 2026-10-26

### Сервер

- Новый сервер получает подборки и коллекции с витрины в первые минуты после установки (раньше мог ждать час).

### Приложение

- Расширенный поиск: фильтры по типу, году, жанру, стране, «В 4K», «Только дубляж», «Рейтинг 7+» и сортировка;
  без текста — подбор по каталогу. Голосовой поиск — кнопкой микрофона на пульте.
- Заказ раздачи в TorBox удержанием ОК — после подтверждения.
- Плеер: отдельные клавиши «пауза» и «воспроизведение» ставят на паузу и запускают, а не переключают.

### Подборки

- Вкладка «Фильмы»: «Цифровые релизы» вместо «Сейчас в кино».

## [0.10] — 2026-10-26

### Сервер

- Админка: ошибка каналов IPTV показывается, только если она про нынешний плейлист и загрузка не идёт.
- Подборки и коллекции сервер скачивает готовыми с витрины — сразу после установки и потом раз в сутки, без своих ключей Кинопоиска; собирает сам, только если скачать не вышло.

### Приложение

- «Следить» в карточке сериала: новые серии с озвучкой появляются в «Моё» → «Новые серии».
- Невышедшие серии не выбираются: в карточке видна ближайшая с датой выхода, автопереход на неё не ведёт.

## [0.9] — 2026-10-24…26

### Установщик

- Сервер обновляется сам каждую ночь: установщик ставит ежедневное задание (Linux — cron, Windows — планировщик
  заданий). Если сервер ставили раньше — запустите установку ещё раз, настройки и база сохранятся.

### Сервер

- IPTV: без своего плейлиста вкладка «ТВ» работает на открытых списках агрегатора m3u.su: сервер берёт эфирные
  федеральные, развлекательные, кино, сериальные, музыкальные, спортивные, детские, познавательные каналы и каналы
  о природе и хобби — без новостей, политики, региональных, магазинов и видеоархивов; убирает дубли и копии со
  сдвигом времени, прячет неработающие и слишком медленные. Свой плейлист в админке
  заменяет открытые списки целиком; открытые списки можно выключить. Религиозные каналы не показываются.
- IPTV: группы открытых списков — по-русски и по числу каналов, мелкие — в «Разное».

### Приложение

- Вкладка «ТВ»: влево из сетки — на текущую группу; тёмные логотипы осветляются; название в фокусе видно.
- Главная: «Назад» по шагам — вкладки, «Главная», выход; фокус не пропадает после выбора вкладки.
- Плеер: на паузе часы и «закончится в» идут.

## [0.1.175] — 2026-10-23

### Сервер
- IPTV: ссылка на плейлист M3U задаётся в админке, сервер сам разбирает каналы и кэширует логотипы.
- Коллекции получили группу, описание, обложку и логотипы студий для новой вкладки; добавлены семнадцать коллекций
  (франшизы, темы, каналы, режиссёры).
- Коллекции: «Сериалы Netflix» и «Фильмы Netflix».

### Приложение
- Плеер: ОК во время просмотра открывает панель управления и не прерывает видео; пауза — вторым ОК или кнопкой на пульте.
- Вкладка «ТВ»: каналы IPTV по группам с избранным; в эфире переключение вверх/вниз, набор номера, список каналов по ОК.
- Кнопка «Кино»: телеканал из случайных фильмов с оценкой от 7, которые включаются мгновенно из кеша TorBox;
  по окончании — следующий.
- Оценка Кинопоиска в карточках рядом с IMDb (нужен ключ kinopoisk.dev на сервере); оценки подгружаются заранее.
- Длинные названия в шапке не переносятся по буквам: шрифт уменьшается; заминусованные логотипы TMDB не используются.
- Вкладка «Коллекции»: плитки по группам вместо рядов, внутри коллекции — описание, состав и карточки по порядку,
  рядом соседние коллекции; название фильма в фокусе — справа сверху над кадром.
- Раздел «Моё»: заказы TorBox разделены на ряды «Готово в TorBox» и «Качается в TorBox».

## [0.1.94] — 2026-10-22

### Сервер
- Новый бэкенд одним `docker-compose`: Caddy (единственный вход, только домашняя сеть), API, JacRed, TorrServer.
  Доступ по ключу устройства на все запросы, включая видео.
- Админка переписана: обзор состояния, журнал воспроизведения, обновления компонентов, настройки устройств и ключей;
  адаптивна для компьютера и телефона.
- База раздач JacRed обновляется синком; в админке виден прогресс и состав базы по трекерам.
- Видео из кеша TorBox отдаётся через сервер по домашней сети: буфер на сервере и переподключение к CDN при
  коротких сбоях, плеер их не замечает.
- Подборки главной собирает сервер по расписанию, кадры и логотипы выбираются заранее.

### Приложение
- Экран подготовки воспроизведения: логотип, продолжение с места остановки, серия с названием, оценки.
- Плеер обновлён (Media3 1.9): точнее перемотка в Matroska, лучше поддержка Dolby Vision, DTS-HD, субтитров SSA и VobSub,
  аппаратный VC-1.
- Оценка IMDb в карточке и на главной, подборки с учётом оценки, коллекция IMDb Top 250.
- Свои коллекции: франшизы, студии, режиссёры, тематические подборки сериалов; в ряду только то, что реально
  можно посмотреть.
- Заказ раздачи в TorBox из карточки и из списка раздач, прогресс загрузки, удаление заказа.
- Исправлено: фокус в карточке сразу на «Смотреть»; «Назад» возвращает на ту же плитку; выбор раздачи из кеша
  TorBox по качеству, а не по сидам; поиск сиквелов с римскими цифрами и порядковыми числами; обрыв потока
  TorBox больше не прерывает просмотр с ошибкой TorrServer; таймаут при пропаже TorrServer во время буферизации.
