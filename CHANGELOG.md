# История изменений для витрины

Это публичная версия `CHANGELOG.md`: уходит в репозиторий-витрину как есть. Правила:
- только то, что видит пользователь, и техническая суть изменения;
- **без названий фильмов и сериалов**, без примеров «на таком-то фильме», без цифр размеров конкретных раздач;
- без адресов, имён хостов, контейнеров, устройств, путей на нашем сервере и имён трекеров как «примеров сбоя»;
- без упоминаний нашего домашнего железа и истории переезда; «сервер» — это сервер пользователя.

Внутренний `CHANGELOG.md` остаётся подробным, с примерами, — он для нас. Публичную запись пишем при выпуске,
одновременно с переносом «Не выпущено» в версию.

## [0.1.94] — 2026-10-22

### Сервер
- Новый бэкенд одним `docker-compose`: Caddy (единственный вход, только домашняя сеть), API, JacRed, TorrServer.
  Доступ по ключу устройства на все запросы, включая видео. Lampac больше не используется.
- Админка переписана: обзор состояния, журнал воспроизведения, обновления компонентов, настройки устройств и ключей;
  адаптивна для компьютера и телефона.
- База раздач JacRed обновляется синком; в админке виден прогресс и состав базы по трекерам.
- Видео из кеша TorBox отдаётся через сервер по домашней сети: буфер на сервере и переподключение к CDN при
  коротких сбоях, плеер их не замечает.
- Подборки главной собирает сервер по расписанию, кадры и логотипы выбираются заранее.

### Приложение
- Экран подготовки воспроизведения: логотип, продолжение с места остановки, серия с названием, оценки.
- Плеер обновлён (Media3 1.9): точнее перемотка в Matroska, лучше поддержка Dolby Vision, DTS-HD, субтитров SSA и VobSub,
  аппаратный VC-1.
- Оценка IMDb в карточке и на главной, подборки с учётом оценки, коллекция IMDb Top 250.
- Свои коллекции: франшизы, студии, режиссёры, тематические подборки сериалов; в ряду только то, что реально
  можно посмотреть.
- Заказ раздачи в TorBox из карточки и из списка раздач, прогресс загрузки, удаление заказа.
- Исправлено: фокус в карточке сразу на «Смотреть»; «Назад» возвращает на ту же плитку; выбор раздачи из кеша
  TorBox по качеству, а не по сидам; поиск сиквелов с римскими цифрами и порядковыми числами; обрыв потока
  TorBox больше не прерывает просмотр с ошибкой TorrServer; таймаут при пропаже TorrServer во время буферизации.
